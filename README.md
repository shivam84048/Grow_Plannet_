# Grow_Plannet

Grow_Plannet is a platform for plant disease detection, crop recommendations, bidding, and agricultural news.

## Features

- Plant disease detection using Plant.id API
- Crop recommendation using machine learning
- Bidding and selling platform for crops
- Latest agricultural news integration

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/shivam84048/Grow_Plannet_.git
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Set up your `.env` file with required API keys and database credentials.
4. Start the server:
   ```
   node src/server.js
   ```

## Environment Variables

- `PLANT_ID_KEY` – Plant.id API key
- `NEWSAPI` – NewsAPI key
- (Optional) Database credentials if not hardcoded
